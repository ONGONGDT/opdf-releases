## v0.1.2

### Sign in
- Sign in with your work Microsoft account (single sign-on). Without signing in, the app opens documents in view-only mode.
- Marks you add are authored by your signed-in account name.
- Your session is re-checked in the background and keeps working offline for up to 15 days.
- If someone else signed out on the same Windows session, Sign in now asks which account to use.

### Stamps
- Create your own stamps: image, PDF, text and dynamic stamps, with a Professional Wordmark look for text stamps.
- Stamp library and picker, Replace Stamp and Manage Stamps.
- Stamps open correctly in Adobe Acrobat: resizing or editing a stamp there no longer crops or distorts it.
- Stamps keep their orientation after saving a turned page.

### Pages
- Right-click a page thumbnail for page commands (Insert, Extract, Duplicate, Rotate, Move, Crop, Rename, Clear names, Delete); right-click empty space for Insert at End, Sort and Select All.
- Select several pages with the keyboard or a rubber-band drag.
- Rotate menu on the floating bar: choose a direction, then rotate the current page or all pages (undoable, saved into the file).
- Insert Pages opens on a one-line location summary (default: right after the current page); Change reveals the Start / After page / End chooser.
- Rename Pages and Bookmark Generate read page regions about 3x faster on large documents, show "Extracting N of M..." progress, and stop when you close the dialog.

### Comments and marks
- Comments panel: the Conversation Navigator replaces the card list, and the search box opens on demand.
- Copy to Pages: copy marks onto other pages in one undo step.
- Ctrl-drag marquee outlines the marks it would select while you drag.

### Zoom and navigation
- Zoom Region tool (Z, next to the zoom controls): drag a box and the view centres it at about 80% of the window.
- Middle-button double-click fits the page, with any tool active.
- Smoother mouse-wheel zoom at 150% and above; a hard wheel push zooms out quickly.
- Zoom steps with a true-size % label; Alt+Wheel for fine zoom.
- The active document tab scrolls into view in the tab strip when you switch tabs.

### Interface
- Toolbars: easier rejoin (one click on a hover-only link), bars fold overflow into "..." popups instead of spilling past the canvas, and each bar keeps its own orientation. Your saved toolbar layout is reset to the default once.
- App Tour and a Controls & Shortcuts Quick Guide.
- One consistent set of keyboard shortcuts.
- PDF files show a dedicated 360PDF icon when 360PDF is the default app.
- Controls for features that are not finished yet are hidden or disabled.

### Fixes
- Text boxes, callouts and typewriter text placed on a turned page now read upright.
- Text boxes keep a size changed from the Format flyout, and the caret and selection follow centred and right-aligned lines.
- Double-click, right-click and Ctrl+wheel no longer reach marks hidden under a dialog or a floating bar.
- Nested popups (Rotate, View mode, Stamp) no longer close the popup that opened them.
- A one-page document can now be selected.
- Opening a file at startup and Save As no longer fail on some file paths.
- Auto-update keeps an already downloaded update package when it re-checks in the background.
- The duplex option in the Print dialog reads "Print on both sides", and truncated labels no longer show two tooltips.
