## v0.1.2-beta.2

### New
- Stamps: create your own image, PDF, text and dynamic stamps; Replace Stamp and Manage Stamps; a Professional Wordmark look for text stamps.
- Rotate menu on the floating bar: choose a direction, then rotate the current page or all pages (undoable, saved into the file).
- Insert Pages: opens on a one-line location summary (default: right after the current page); Change reveals the Start / After page / End chooser.
- PDF files show a dedicated 360PDF icon when 360PDF is the default app.
- Zoom-in with the mouse wheel is rate-limited at deep zoom so it no longer overshoots.

### Fixes
- Stamps open correctly in Adobe Acrobat: resizing and editing a stamp there no longer crops or distorts it.
- Auto-update keeps an already downloaded update package when it re-checks in the background.
- Text boxes: a size changed from the Format flyout is kept on commit; the caret and selection follow centred and right-aligned lines.
- App Tour no longer skips the Comments step on fast computers.
