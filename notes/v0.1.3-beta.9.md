## v0.1.3-beta.9

### Fixes
- Saving no longer breaks digital signatures. Earlier versions could rewrite a signed PDF when saving it, which made its signatures invalid.
- Text boxes keep their orientation and line spacing after the file is opened and saved in Adobe Acrobat.

### Changes
- **Signed PDFs:**
  - The original file is never changed. Markup you add is saved to a copy. After that, the tab switches to the copy, and later saves add to it.
  - Certified PDFs, and PDFs whose signature can't be checked, can be viewed or saved as an exact copy only.
  - Page changes, cropping, bookmark edits and text replacement are not available on signed PDFs.
- **Save As on a signed PDF with no changes:** saves an exact copy, so the signature stays intact. The old "export without signature" warning is gone.
- **"Saved" message:** no longer shown when part of the save failed.
