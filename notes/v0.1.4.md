## v0.1.4

### Fixes
- **Network printers now show up in Print.** Printers connected through a print server (for example `\\server\printer`) were missing from the printer list, even though Windows and other PDF apps showed them. They are now listed and can be printed to.
- **The Print dialog no longer freezes on a slow printer.** Printers are checked in the background, so a slow or unreachable print server doesn't freeze the app.

### Changes
- **Printer list:**
  - Printers are grouped into *This computer* and *Network*.
  - Network printers show a short name with their server, for example "HP-4F-Color on srv01".
  - The list updates by itself when a printer is added or removed in Windows.
  - New *Refresh* and *Add a printer…* items at the end of the list. *Add a printer…* opens the Windows Add Printer window.
- **While a printer is being checked:**
  - Print is disabled, and the dialog says why: "Checking printer…", then "taking longer than usual", then "isn't responding" with a *Retry* button.
  - It is never disabled without a reason.
- **Last printer remembered:**
  - Print starts on the printer your last print went to.
  - If you change the default printer in Windows, the new default is used instead.
  - If the remembered printer isn't available, Print switches to your default printer, says so, and offers *Use … anyway*.
