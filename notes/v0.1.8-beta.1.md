## v0.1.8-beta.1

### Features
- Sharper screen rendering of drawings: thin horizontal and vertical lines are drawn as crisp whole-pixel lines, as in Acrobat. LCD text with stroke snap is now the default; printing and export are unchanged.

### Performance
- Faster, smoother start: the window no longer flashes black or jumps to its saved size, and the first window appears about half a second sooner.

### Bug Fixes
- Opening a file whose name ends in an accented character (for example "MB CÁC TẦNG") no longer crashes the app a second after it opens.
- With several windows open, the "waiting for render" bar now shows in each window.
