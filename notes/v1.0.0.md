## v1.0.0

First stable release.

### Viewing
- Open PDFs by file, drag-and-drop, or as the default PDF app.
- Handles large files (hundreds of pages) and dense vector drawings without freezing.
- Continuous Scroll, Single Page, and Side-by-Side view modes.
- Zoom from 10% to 1000%, with Fit Width, Fit Page, and Actual Size shortcuts.
- Thumbnail sidebar for quick page jumps.
- Multiple files open in tabs, with unsaved-changes tracking per tab.
- Recent Files list.
- Vietnamese text and diacritics render correctly.

### Page tools
- Insert, duplicate, delete, rotate, crop, rename, sort, and reorder pages.
- Insert pages from another PDF, or extract pages out to a new one.
- Merge multiple PDFs into one.

### Bookmarks
- View a PDF's existing bookmarks.
- Add and organize your own bookmarks, saved into the file.

### Markup and annotations
- Highlight, underline, strikeout, sticky notes, text boxes, callouts, freehand drawing, lines, arrows, rectangles, ellipses, cloud shapes, and stamps.
- Rich text formatting inside text boxes: font, size, and color per selection.
- Annotations are saved as standard PDF objects, so they stay editable and removable later, in OPDF or any other PDF reader.

### Comments
- Reply threads on comments.
- Resolve and reopen threads.
- Comments panel to list and jump to comments.

### Printing
- Print to physical or virtual printers.

### Updates
- Checks for new versions automatically, downloads and verifies them, and applies the update on restart.

### Performance
- Stays responsive on large, complex drawings.
- Memory use stays stable during long viewing sessions.
