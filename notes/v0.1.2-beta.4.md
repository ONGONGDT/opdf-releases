## v0.1.2-beta.4

### New
- Zoom Region tool (Z, next to the zoom controls): drag a box and the view centres it at about 80% of the window. Esc cancels a drag; Esc again returns to Select.
- Middle-button double-click fits the page, with any tool active.
- Ctrl-drag marquee now outlines the marks it would select while you drag.
- Deep-zoom mouse wheel is smoother: at 150% and above each notch is a small step, and a hard wheel push zooms out quickly.
- Toolbars: easier rejoin (one click on a hover-only link), bars fold overflow into "..." popups instead of spilling past the canvas, and each bar keeps its own orientation. Your saved toolbar layout is reset to the default once.
- Rename Pages and Bookmark Generate read page regions much faster on large documents (about 3x on a 555-page set), show "Extracting N of M..." progress, and stop when you close the dialog. Changing the page range no longer rescans.

### Fixes
- Signing in after someone else signed out on the same Windows session now asks which account to use, instead of signing in as the Windows user again.
- Double-click, right-click and Ctrl+wheel no longer reach marks hidden under a dialog or a floating bar.
- Nested popups (Rotate, View mode, Stamp) no longer close the popup that opened them.
