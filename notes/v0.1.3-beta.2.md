
## v0.1.3-beta.2

### New
- Updating is no longer a blank wait. When 360PDF closes to install an update, a small "360PDF Update" window shows what is happening (closing, checking, installing, starting) and closes by itself when the new version opens. If something goes wrong, it says so and offers "Open 360PDF" and "View log" instead of leaving you waiting. This appears for updates installed from this version onward.

### Fixes
- Faster updates on computers where Windows runs the installer with full administrator rights: the installer no longer waits about 10 seconds for the background update service before starting.
