## v0.1.2-beta.3

### New
- Pages panel: right-click a page thumbnail for page commands (Insert, Extract, Duplicate, Rotate, Move, Crop, Rename, Clear names, Delete); right-click empty space for Insert at End, Sort and Select All.
- The active document tab now scrolls into view in the tab strip whenever you switch tabs.

### Fixes
- Truncated labels (Rename pages, Sort pages, comment reply bylines) no longer show two tooltips stacked on top of each other.
- Print dialog: the duplex option now reads "Print on both sides".
