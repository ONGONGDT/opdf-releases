
## v0.1.3-beta.1

### Fixes
- Fixed 360PDF not opening at all on some computers with Intel graphics (for example Intel Iris Xe): the app closed immediately, from the desktop icon or from a PDF. The display mode is now chosen from what your graphics driver actually supports, and falls back safely if it does not work. Startup is also about half a second faster.

### New
- Markup styles: each tool now keeps its own Current style. "Save as Default" keeps it for next time, and "Reset to Default" or "Restore Factory Style" bring it back. Restyling a mark right after you draw it changes that tool's style; restyling a mark you picked later changes only that mark.
- Toolbars: the rejoin button now floats outside the markup tray so it no longer covers the tools.
